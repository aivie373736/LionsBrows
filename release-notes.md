The first public release of LionsBrows: a fast, private browser that stays minimal.

## Download

| Your computer | File |
| --- | --- |
| Windows 10 or 11 (most PCs) | `LionsBrows-win-x64.exe` |
| Windows on ARM (Snapdragon laptops) | `LionsBrows-win-arm64.exe` |
| Mac with Apple silicon (M1 and newer) | `LionsBrows-mac-arm64.dmg` |
| Mac with Intel | `LionsBrows-mac-x64.dmg` |
| Linux, 64-bit | `LionsBrows-linux-x86_64.AppImage` |
| Linux on ARM (Raspberry Pi 4/5) | `LionsBrows-linux-arm64.AppImage` |

## First start

- **Windows:** the installer is not code-signed yet, so SmartScreen may say "Windows protected your PC". Click **More info**, then **Run anyway**. On managed PCs, such as school or work computers, an administrator can block this.
- **macOS:** the app is not notarized. Open it once, then go to **System Settings → Privacy & Security** and click **Open Anyway**.
- **Linux:** make the AppImage executable (`chmod +x LionsBrows-linux-*.AppImage`) and start it.

## What's inside

- Tabs on top or on the side, workspaces with separate logins, split view and a command bar (Ctrl+K)
- Built-in ad and tracker blocking, hidden cookie banners, and warnings before known phishing and malware sites
- A password manager that suggests strong passwords on sign-up forms
- Chrome extensions straight from the Chrome Web Store
- Reader view, page translation, automatic picture in picture and QR codes to open a page on your phone
- Import of bookmarks and history from Chrome, Edge, Brave, Vivaldi, Opera and Firefox
- English and German
- Automatic updates on Windows and Linux; on macOS LionsBrows tells you when a new version is out

## Known limitations

- Netflix and some other streaming services may not play yet, because this build has no Widevine VMP signature.
- Extensions that rely on `chrome.webRequest` or some newer Chrome APIs only work partly.
